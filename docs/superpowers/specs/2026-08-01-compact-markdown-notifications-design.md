# 轻量 Markdown QQ 通知

## 目标

QQ 通知只展示用户需要理解和处理的信息，移除调度器、追踪和内部来源字段，并使用轻量 Markdown 建立清晰层级。

## 输出格式

- 标题使用三级 Markdown 标题：`### 标题`。
- 标题与正文之间保留一个空行。
- 业务正文由调用方提供，可使用 `**对象**`、列表和引用。
- “下一步”使用引用行：`> 下一步：...`。
- 通用渲染器不再附加 `status`、`source`、`trace_id` 和时间。

## 模板行为

- Cron 成功显示“定时任务完成”，失败显示“定时任务异常”，正文只保留摘要。
- Cron 不再显示任务名、Cron 表达式、Job、Schedule 或英文状态。
- CI 和 Codex 模板改用中文标题和字段，不输出文件清单、追踪 ID 等内部信息。
- 普通业务通知保留调用方标题和正文，不加入额外元数据。

## 发送方式

`qqnotifyd` 优先通过 QQ C2C Markdown 消息发送，消息体使用 `msg_type=2` 和 Markdown content。文本发送接口继续保留，保证库的兼容性和测试替身可用。

## 验收

- 单元测试精确验证 Markdown 文本和 QQ 请求载荷。
- 部署 PanSou 后在容器中生成最终消息样例。
- 仅在明确验证时发送一条标记为格式验证的真实 QQ 消息。
